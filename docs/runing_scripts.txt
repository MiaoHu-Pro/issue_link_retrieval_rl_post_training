test all datasets (new command):
Use these four commands after the corresponding exhaustive training jobs complete.
  Because training used no --run-suffix, testing also uses no --adapter-suffix.

  ### Base, set retrieval

  sbatch --partition=i7_h200 --gres=gpu:1 \
    --job-name=eval-set-base-all-test \
    scripts/evaluation/submit_evaluate_sft.sh \
    --task set_retrieval \
    --initialization base \
    --model-dataset all \
    --eval-dataset all \
    --split test \
    --data-version v1_full

  ### CPT, set retrieval

  sbatch --partition=i7_h200 --gres=gpu:1 \
    --job-name=eval-set-cpt-all-test \
    scripts/evaluation/submit_evaluate_sft.sh \
    --task set_retrieval \
    --initialization cpt \
    --model-dataset all \
    --eval-dataset all \
    --split test \
    --data-version v1_full

  ### Base, pointwise

  sbatch --partition=i7_h200 --gres=gpu:1 \
    --job-name=eval-pw-base-all-test \
    scripts/evaluation/submit_evaluate_sft.sh \
    --task pointwise \
    --initialization base \
    --model-dataset all \
    --eval-dataset all \
    --split test \
    --data-version v1_full \
    --threshold 0.5

  ### CPT, pointwise

  sbatch --partition=i7_h200 --gres=gpu:1 \
    --job-name=eval-pw-cpt-all-test \
    scripts/evaluation/submit_evaluate_sft.sh \
    --task pointwise \
    --initialization cpt \
    --model-dataset all \
    --eval-dataset all \
    --split test \
    --data-version v1_full \
    --threshold 0.5

  The all evaluations process the test splits of Apache, Jira, RedHat, MongoDB, Qt, and
  Mojang. Results are saved under:

  experiment_results/evaluation/
    qwen3.5-9b-{base|cpt}-sft-{set|pointwise}-all-v1-full/
    all-v1_full/test/full/

  Each result contains:

  metrics.json
  predictions.jsonl.gz
  run_config.json

  For final pointwise classification results,
  select the threshold on validation first:

  sbatch --partition=i7_h200 --gres=gpu:1 \
    --job-name=eval-pw-cpt-all-validation \
    scripts/evaluation/submit_evaluate_sft.sh \
    --task pointwise \
    --initialization cpt \
    --model-dataset all \
    --eval-dataset all \
    --split validation \
    --data-version v1_full \
    --select-threshold

  Then use the value in selected_threshold.json as --threshold VALUE for
  the test job.
  Ranking metrics such as MAP, MRR, Recall@k, Hits@k,
  and nDCG@k do not depend on this
  threshold.
